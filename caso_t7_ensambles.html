ESTACIÓN 1 · 20–25 MIN

La empresa necesita pronosticar sus ventas

La dirección debe planear el inventario de las próximas semanas. Tres modelos (A, B y C) ofrecen predicciones diferentes. Para tomar una decisión necesitamos saber cuál se aproxima más a las ventas que realmente ocurrieron.

Tu misión: comparar predicciones con ventas reales, medir sus errores y decidir si combinar modelos ayuda a reducir el error. Primero comprenderás cómo se combinan; después comprobarás los cálculos.

Este es un ejemplo didáctico de 8 semanas, distinto de las 47 semanas históricas del caso original. No se entrenaron modelos reales de bagging, boosting o stacking en esta página. Usaremos una media de pronósticos solo para mostrar la idea básica de combinación.

1. Comprende antes de calcular

¿Qué es un pronóstico? Una estimación de algo que todavía no conocemos. Por ejemplo, «la próxima semana venderemos 110 unidades». Una vez que termina la semana podemos comparar esa predicción con la venta real.

Ejemplo sencillo: pronóstico = 115 unidades; venta real = 110 unidades.
Error absoluto = |110 − 115| = 5 unidades
Usamos el valor absoluto para que equivocarse por exceso o por defecto cuente como error positivo.

¿Qué hacen los ensambles?

Un ensamble combina varios modelos para producir una predicción final. Los tres métodos del temario se diferencian principalmente en cómo entrenan y combinan sus modelos.

Bagging

Muestra 1 → Árbol 1Muestra 2 → Árbol 2Muestra 3 → Árbol 3↓Promedio o voto

Idea: varios modelos se entrenan en paralelo usando distintas muestras de entrenamiento. Sus resultados se agregan.

Ejemplo: Random Forest. Busca reducir la inestabilidad o variabilidad de un solo árbol.

Boosting

Modelo 1→Corrige errores→Modelo 2→Conjunto

Idea: se construyen modelos secuencialmente; cada nuevo modelo busca mejorar fallos del conjunto anterior.

Ejemplo: AdaBoost o Gradient Boosting. Puede requerir ajustar cuidadosamente sus parámetros.

Stacking

Modelo AModelo BModelo C↓Modelo combinador

Idea: un modelo adicional aprende cómo combinar las predicciones de los modelos base.

Se entrena con predicciones fuera de muestra para evitar que aprenda de resultados indebidamente filtrados.

La diferencia esencial: bagging agrega modelos entrenados con remuestreo; boosting aprende por etapas; stacking aprende una regla de combinación mediante otro modelo. Hacer un promedio simple no equivale a demostrar ninguno de estos tres métodos.

2. ¿Por qué aparece «Promedio A–C»?

Supongamos que los modelos A, B y C pronostican la misma semana. Podemos construir un cuarto pronóstico combinado calculando su media aritmética. No es un cuarto modelo entrenado: es una regla de combinación.

Modelo A

115 u.Pronóstico semana 1

Modelo B

105 u.Pronóstico semana 1

Modelo C

112 u.Pronóstico semana 1
Promedio A–C = (115 + 105 + 112) / 3 = 110.67 unidades
Venta real = 110 → Error absoluto combinado = |110 − 110.67| = 0.67 unidades

En esta semana, combinar fue útil porque algunos modelos sobreestimaron y otro subestimó las ventas. La prueba importante es verificar si también ayuda en las demás semanas.

3. Compara ocho semanas y formula tu hipótesis

Objetivo de la comparación: elegir el pronóstico con el menor error absoluto medio (MAE) al compararlo contra ventas reales. Las ventas reales son la referencia con la que medimos las predicciones.

4. Descubre el error y verifica tu hipótesis

Primer paso: para cada semana y alternativa, restamos la predicción de la venta real y tomamos su valor absoluto. Segundo paso: sumamos los ocho errores y dividimos entre 8.

MAE = (|real₁ − pronóstico₁| + … + |real₈ − pronóstico₈|) / 8
