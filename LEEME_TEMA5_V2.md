## Validación en VS Code
1. Descomprimir todo el ZIP en una carpeta aparte.
2. Abrir la carpeta con VS Code y lanzar Live Preview o Live Server.
3. Abrir `index.html` y comprobar el acceso a Tema 5 debajo de Tema 4.
4. Recorrer las cuatro estaciones; probar respuestas adecuadas e inadecuadas, copia y descarga.
5. No publicar en GitHub hasta revisar los cambios.

Los archivos del caso de los temas 1–4 se conservan sin cambios salvo `index.html`. El contenido del Avance de proyecto 2 es solo una lista de apoyo, no un solucionario.
