# Tema 5 — Laboratorio de visualización (prueba local)

1. Descomprime el ZIP en una carpeta.
2. Abre toda la carpeta en VS Code y utiliza **Live Server**.
3. Inicia en `caso_inventarios_tema5.html`.
4. Comprueba estaciones 1–4, la defensa y navegación; prueba también desde un móvil.
5. Conserva los HTML y XLSX anteriores: el paquete los incluye y agrega los nuevos módulos.
6. Una vez validado localmente, sube a la raíz del mismo repositorio GitHub (rama main). **No subas el ZIP directamente**.

## Pruebas rápidas
- Estación 1: elegir barras para comparar políticas da retroalimentación correcta.
- Estación 2: la afirmación B es la defendible. Los beneficios son ~£166.39 y £167.99.
- Estación 3: Q=270 cuesta £229.50, beneficio ~£166.39; Q=293 cuesta £249.05, beneficio ~£167.99, no es factible con £230.
- Estación 4: probar copiar y descargar el texto completado.

## Limitaciones
El sitio es estático y funciona sin cuentas ni servicios de Microsoft; las respuestas no se reciben automáticamente. La lectura sobre Tableau/Power BI se aborda en lo conceptual. Los datos de ventas son un proxy de demanda; no se conoce la demanda perdida. El Avance de proyecto 2 utiliza otro caso, no se resuelve aquí.
