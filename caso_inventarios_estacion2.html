El encargo de la gerencia

La empresa debe decidir cuántas bolsas 20725 · Lunch Bag Red Retrospot preparar para una semana. La dirección pide una estimación económica para tres alternativas, usando el promedio histórico como escenario de referencia.

Objetivo: comparar las tres alternativas mediante el mismo modelo, identificar los supuestos y elegir una recomendación provisional.

La información histórica refleja ventas registradas, no demanda no atendida. Para el ejercicio se tratará el promedio de ventas como proxy de demanda esperada, con una limitación explícita.

  3. Revisen precio, costo y recuperación en B7:B9.

1. Distingan hechos de supuestos

Dato observado

47 semanas

Ventas históricas filtradas de la base UCI. El promedio es una estadística calculada, no una certeza.

Variables de decisión

Q = ?

Inventario a preparar: 250, 300 o 400 unidades por semana.

Hipótesis didácticas

£ / unidad

Precio, costo y recuperación. No son costos verificados de la empresa UCI.

Estos controles sirven para explorar el modelo después de resolverlo en Excel. Al cambiar un valor se recalculan los tres escenarios, pero sigue siendo un modelo determinístico.

Ventas realizadas = MIN(Q, venta esperada)
Excedentes = MAX(Q − venta esperada, 0)
Beneficio (£) = ventas realizadas × precio + excedentes × recuperación − Q × costo
Importante: se supone que todo el inventario preparado se compra o produce esa semana y los excedentes se liquidan al valor de recuperación. No se modelan faltantes de demanda no observada, existencias iniciales, ni inventario que pasa a la semana siguiente.

2. Calculen primero en Excel y comprueben aquí

Completen las tres cifras de beneficio obtenidas en Modelo_fijo!B13. Seleccionen «Comprobar» para contrastarlas con los parámetros que aparecen arriba.

Comprueba que en Excel cambiaste solo Modelo_fijo!B5 y registraste B13 para cada cantidad. Si el cálculo no coincide, revisa las celdas B6:B9 y si se está usando MIN y MAX correctamente.

Puente hacia el tema 3

Pregunta detonante: el modelo tiene una salida fija cuando sus entradas son fijas. Si las ventas semanales cambian mucho, ¿qué tan confiable es decidir solamente con el promedio?
