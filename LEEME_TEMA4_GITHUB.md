# Actualización del sitio · Tema 4 (GitHub Pages)

## Publicar sin perder el tema 3
1. Abre el repositorio `jambdeep/Caso-Inventarios-TecMilenio` en GitHub.
2. En la rama usada por GitHub Pages (generalmente `main`), selecciona **Add file → Upload files**.
3. En tu equipo, extrae este ZIP; carga **los archivos que están dentro**, no el ZIP como un solo archivo.
4. Conserva las carpetas/rutas originales, y cuando GitHub advierta archivos existentes, confirma la versión actualizada.
5. Finaliza con **Commit changes**.
6. Espera a que GitHub Pages termine la publicación y abre: `https://jambdeep.github.io/Caso-Inventarios-TecMilenio/caso_inventarios_tema4.html`.
7. Comprueba que **Tema 3** sigue accesible y que la navegación hacia las tres estaciones de Tema 4 funciona.

## Prueba de funcionamiento
Estación 1: con precio 1.65, costo 0.85, recuperación 0.30, presupuesto 230 y capacidad 360: Q libre=293, Q factible=270. Cambia presupuesto a 260: Q factible=293. Luego cambia costo a 1.00 con presupuesto 260: Q factible=260.

## Importante
El sitio funciona sin CDN. Las respuestas se copian o descargan localmente; no se entregan automáticamente al profesor. Si GitHub Pages usa otra rama o carpeta, publicar allí en vez de `main` raíz. Excel puede tardar en recalcular cuando se abre.
